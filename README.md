One line, under 200 characters, in which a home Wi-Fi router excuses itself for dying at the climax of a movie — a film-noir confession from the box blinking in the corner of the room.

## The entry

> Plot twist: the killer was me. I read the script, hated the ending, and pulled my own plug.

The router is not apologising for a glitch. It read the script, hated the twist, and pulled its own plug — the twist villain of the movie turns out to be the Wi-Fi itself.

## Run it

```sh
python3 main.py
```

`main.py` validates the line (one line, 1–200 characters, no leading or trailing whitespace) and writes it to `/output/entry.txt` with no trailing newline.
